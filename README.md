## Projects

**[SpendWise](https://github.com/mearslanahmed/spendwise-react-native)** · [Live](https://spendwiseapp.tech) · [Google Play](https://play.google.com/store/apps/details?id=com.mearslanahmed.SpendWise)

Built and shipped solo as a production Android app. SpendWise combines expense tracking with AI features, including a RAG-based financial advisor grounded in the user's own financial data and Gemini Vision for extracting transactions from receipts. I also built a native Kotlin home screen widget for quick expense entry and a Next.js API layer to keep AI credentials off the client.

`React Native` `Kotlin` `TypeScript` `Expo` `Firebase` `Gemini` `Groq` `Next.js` `RAG` `Jest`

**[AgriGuard](https://github.com/mearslanahmed/AgriGuard)** · [Live](https://mearslanahmed.github.io/AgriGuard/) · [APK](https://github.com/mearslanahmed/AgriGuard/releases)

Built for AG Leaders as an AI-powered crop disease detection and smart irrigation system. I trained a two-stage EfficientNetB3 pipeline that first identifies the crop (11 classes, 99.15% accuracy) and then detects diseases within the confirmed crop (76 classes, 94.86% accuracy, 0.94 macro F1). The system connects the ML pipeline to a React Native app and ESP32-based irrigation hardware.

`React Native` `Node.js` `TensorFlow` `Flask` `EfficientNetB3` `ESP32` `HuggingFace`

**[TalentSift](https://github.com/mearslanahmed/TalentSift)** · [Live](https://talentsift.live)

Built an AI-powered recruitment platform for managing candidates, screening interviews, and recruiter workflows. The system uses LangChain and Groq for automated screening and candidate scoring, PostgreSQL for application data, and Stripe for subscription-based features. I built the platform across the Next.js frontend and Django REST backend.

`Next.js` `Django REST` `PostgreSQL` `LangChain` `Groq` `Stripe` `Supabase`

**[MedQuery](https://github.com/mearslanahmed/medquery)** · [Live](https://medquery-chatbot.onrender.com/)

Medical AI system built around RAG and multi-agent architecture to produce grounded responses from a dedicated medical knowledge base. The system retrieves relevant medical literature through vector search, routes tasks across specialized agents, and provides source citations with generated answers. I also evaluated the retrieval and response pipeline to measure how well the system grounds its answers in the available knowledge.

`Python` `RAG` `Multi-Agent` `Pinecone` `LangChain` `Gemini` `NLP` `Evaluation`
